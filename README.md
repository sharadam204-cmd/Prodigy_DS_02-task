

## Task 2 – Exploratory Data Analysis

This repository contains my implementation of **Task 2** completed during my **Data Science Internship at Prodigy Infotech**.

The project focuses on performing **data cleaning and Exploratory Data Analysis (EDA)** to discover patterns, relationships, and useful insights from the dataset.

## Objectives

* Load and understand the dataset.
* Examine the structure and characteristics of the data.
* Identify missing and inconsistent values.
* Perform data cleaning and preprocessing.
* Analyze relationships between important variables.
* Create visualizations to communicate the findings.

## Dataset

The repository contains the dataset:

* `train.csv`

The dataset is analyzed using Python and Pandas to understand its variables, distributions, and relationships.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## Methodology

### 1. Data Loading

The dataset is loaded into a Pandas DataFrame.

### 2. Data Exploration

Basic information such as the number of rows, columns, data types, and statistical summaries is examined.

### 3. Data Cleaning

Missing values, duplicate records, and inconsistent data are checked and handled where required.

### 4. Exploratory Data Analysis

Different variables are analyzed to identify relationships and important patterns.

### 5. Data Visualization

Graphs and charts are created to represent the findings clearly.
